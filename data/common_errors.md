# V93K 常见报错与排错指南

## 1 Contact Fail（接触测试失败）

### 1.1 报错表现

测试程序在运行 Contact Test（开路/短路测试）时，特定引脚或全部引脚返回 FAIL。Dlog 中显示 continuity fail 或 contact resistance 超限。

### 1.2 常见原因

| 原因类别 | 具体说明 |
|---------|---------|
| 探针卡/插座接触不良 | 探针磨损、污染、对位偏移；BGA 插座弹簧针疲劳 |
| 被测芯片本身损坏 | 晶圆划伤、封装缺陷导致引脚开路 |
| 电平设置错误 | Contact Test 驱动电流或钳位电压设置不当，导致误判 |
| 板卡通道故障 | 测试机数字通道损坏，输出或采集异常 |

### 1.3 排查步骤

1. **物理检查**：在显微镜下检查探针卡针尖状态，确认是否磨损或污染。用无尘纸蘸异丙醇清洁针尖。
2. **对位校准**：运行 Probe Card Alignment，检查 mark pad 对位精度（X/Y 偏移应 < 5μm）。
3. **换芯片复测**：换一颗已知良品芯片测试，若仍 Fail 则是探针卡或测试机问题；若 Pass 则是被测芯片问题。
4. **检查电平参数**：确认 STIL Levels 文件中 contact test 的驱动电流（通常 100μA~1mA）和钳位电压是否合理。
5. **逐引脚排查**：查看 Dlog 中哪些引脚 FAIL，判断是全部引脚还是个别引脚——全部 FAIL 通常指向系统级问题（电源、地线、探针卡），个别 FAIL 通常是探针卡个别针或芯片该引脚本身问题。

### 1.4 解决方案

- 探针磨损：更换探针卡或重新研磨针尖。
- 对位偏差：重新做 Probe Card Alignment，必要时调整 Handler 的 Pick & Place 参数。
- 电平问题：调整 Levels 文件中 contact test 相关参数，增大驱动电流或放宽钳位。
- 通道故障：用诊断工具（Diagnostics）检查板卡通道，必要时更换板卡或重新插拔。

## 2 Pattern Mismatch（向量比对失败）

### 2.1 报错表现

功能测试执行时，某些周期的实际输出与测试向量中定义的期望值不匹配，Dlog 报告失败的 cycle 号和引脚名。

### 2.2 常见原因

| 原因类别 | 具体说明 |
|---------|---------|
| 芯片功能缺陷 | 芯片逻辑错误，输出确实不符合期望 |
| 时序定义错误 | 驱动边沿/比较边沿时间设置不当，采样时刻不对 |
| 电平阈值错误 | VOH/VOL/VIH/VIL 设置不合理，高低电平判断有误 |
| 向量本身错误 | Pattern 文件中的期望值编写错误 |
| 信号完整性问题 | PCB 走线过长、阻抗不匹配导致信号振铃、串扰 |

### 2.3 排查步骤

1. **查看失败 Cycle**：在 Dlog 中找到第一个失败的 cycle 号和引脚，判断是否集中在某个时间段或某组引脚。
2. **波形检查**：用示波器工具（Scope）抓取失败引脚的实际波形，对比 Timing 中定义的驱动/比较时间点。
3. **放宽时序重测**：把比较边沿往后推 2-3ns，看是否 PASS——如果 PASS 则说明原始时序太临界。
4. **换向量比对**：用 Golden Device（已知良品）跑同一套 Pattern，判断是芯片问题还是测试设置问题。
5. **检查 Levels**：确认 VIH/VIL/VOH/VOL 是否覆盖芯片规格书要求。

### 2.4 解决方案

- 芯片缺陷：记录 Bin Code，属正常测试筛出的不良品。
- 时序问题：调整 Timing 文件中比较边沿时间，建议预留 10-20% 的时序余量。
- 电平问题：调整 Levels 文件，确保 VIH < 芯片输出 VOH，VIL > 芯片输出 VOL。
- 向量错误：修正 Pattern 文件中的期望值。
- 信号完整性：缩短探针卡走线，优化阻抗匹配。

## 3 Over Voltage / Over Current（过压/过流保护）

### 3.1 报错表现

测试机触发硬件保护，报告 over voltage 或 over current 错误，测试中断。可能发生在 DPS 供电通道或数字通道上。

### 3.2 常见原因

| 原因类别 | 具体说明 |
|---------|---------|
| 供电设置错误 | DPS 电压设置超过芯片或探针卡耐压 |
| 电流钳制过低 | 电流限制（Clamp）设得太小，正常工作电流就超限 |
| 芯片短路 | 芯片内部电源与地短路，电流暴增 |
| 探针卡短路 | 探针之间或探针与基板短路 |

### 3.3 排查步骤

1. **确认保护阈值**：检查 DPS 设置的电压和电流钳制值，与芯片规格书对比。
2. **断开芯片测试**：不放芯片，仅运行 DPS 供电程序，看电流是否仍超限——若超限则是探针卡短路。
3. **逐电源域排查**：逐个开启 VDD/VDDIO/VDDCORE 等电源域，定位是哪个电源域触发保护。
4. **量测电阻**：用万用表量测探针卡上各电源 pin 与地之间的电阻，正常应为 kΩ 级别，若为 Ω 级则短路。

### 3.4 解决方案

- 设置错误：修正 DPS 电压和电流钳制参数。
- 芯片短路：记录 Bin Code，芯片不良。
- 探针卡短路：检查探针卡 PCB，排除焊点桥连或走线损坏。

## 4 良率骤降（Yield Drop）

### 4.1 报错表现

某段时间内测试良率突然从 95%+ 下降到 80% 以下，无特定报错，表现为多种 Bin Code 的 Fail 数同时增加。

### 4.2 常见原因

| 原因类别 | 具体说明 |
|---------|---------|
| 探针卡老化 | 连续使用数万次后探针磨损，接触电阻增大 |
| 温度漂移 | 机台温控异常或环境温度变化导致测试条件偏移 |
| 晶圆批次差异 | 不同批次 wafer 的工艺波动 |
| 测试程序版本错误 | 误用了错误的测试程序或参数文件 |

### 4.3 排查步骤

1. **检查时间窗口**：良率下降从哪一批次/Wafer 开始？与探针卡使用次数、环境温度变化是否对应。
2. **Bin Code 分析**：统计各 Bin Code 的 Fail 占比，若集中在某几个 Bin 则指向特定测试项问题。
3. **Shmoo 测试**：对关键参数（电压、频率）做 Shmoo，比较当前与良率正常时的 Shmoo 边界。
4. **Golden Device 复测**：用已知良品芯片跑完整测试流程，若 Fail 则是测试系统问题。
5. **程序版本核对**：确认当前测试程序版本、参数文件版本是否与良率正常时一致。

### 4.4 解决方案

- 探针卡老化：更换探针卡。
- 温度问题：检查温控系统（Thermal Head），校准温度传感器。
- 工艺波动：与晶圆厂沟通，提供 Wafer Map 和 Bin Map 数据做交叉分析。
- 程序版本：回滚到已知良率正常的程序版本。

## 5 单引脚持续失败（Single Pin Fail）

### 5.1 报错表现

某一颗芯片的特定引脚在所有测试项中持续 FAIL，而同 Wafer 其他芯片该引脚正常。

### 5.2 常见原因

| 原因类别 | 具体说明 |
|---------|---------|
| 芯片引脚缺陷 | 该引脚对应的 IO 单元损坏（ESD 击穿、封装缺陷） |
| 探针对应针问题 | 该引脚对应的探针磨损或污染 |
| 板卡通道问题 | 测试机上分配给该引脚的通道故障 |

### 5.3 排查步骤

1. **交换引脚映射**：在测试程序中将该引脚分配到另一个空闲通道，重测——若 PASS 则是原通道故障，若仍 FAIL 则是芯片或探针卡问题。
2. **换芯片测试**：同通道测另一颗芯片该引脚——若 PASS 则是原芯片该引脚缺陷。
3. **检查探针**：显微镜检查该引脚对应探针的状态。

### 5.4 解决方案

- 通道故障：更换板卡或重新分配通道。
- 芯片缺陷：正常筛出，记录 Bin Code。
- 探针问题：清洁或更换该探针（若探针卡支持单针更换）。

## 6 测试程序加载失败

### 6.1 报错表现

SmarTest 加载测试程序时报错，常见错误如 "compile error"、"missing file"、"syntax error in STIL"。

### 6.2 常见原因与解决

| 错误类型 | 原因 | 解决 |
|---------|------|------|
| STIL syntax error | STIL 文件中关键字拼写错误、括号不匹配、分号遗漏 | 检查报错行号，修正语法 |
| missing include file | STIL 文件引用了不存在的 include 文件 | 确认 include 路径和文件名 |
| compile error (C++) | Test Method 编译失败，常见于 API 调用参数类型不匹配 | 检查编译器报错信息，修正 C++ 代码 |
| pattern file not found | STIL 中引用的 Pattern 文件路径错误 | 修正 Pattern 文件路径或放入正确目录 |
| version mismatch | 测试程序版本与 SmarTest 软件版本不兼容 | 确认 SmarTest 版本，必要时升级程序 |

## 7 Shmoo 图异常

### 7.1 报错表现

Shmoo 测试结果图（电压-频率二维扫描）出现异常形状，如大面积 Fail、不规则边界、突然断崖。

### 7.2 常见异常形态与诊断

| Shmoo 形态 | 可能原因 |
|-----------|---------|
| 大面积 Fail（低电压区） | 电源供电不足、接触电阻大、芯片 VDD 域设计余量不足 |
| 高频区突然全 Fail | 芯片时钟树设计上限，属正常特性 |
| 不规则锯齿边界 | 信号完整性问题（串扰、反射），或探针卡阻抗不连续 |
| 局部热点 Fail | 芯片局部缺陷（如某功能模块逻辑错误） |

### 7.3 排查建议

- 对比 Golden Device 的 Shmoo：边界形状一致说明测试设置正常，芯片个体差异导致。
- 调整 Shmoo 步进：缩小电压/频率步进粒度，精确定位边界。
- 多温度点 Shmoo：在高温/低温下分别跑 Shmoo，判断是否温度敏感。
